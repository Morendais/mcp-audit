# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.2.x   | Yes       |
| < 0.2.0 | No        |

## Reporting a Vulnerability

The `mcp-audit` project is committed to ensuring the security of the Model Context Protocol ecosystem. If you discover a vulnerability in `mcp-audit`, please report it responsibly.

### How to Report
Please **DO NOT** create a public GitHub issue for security vulnerabilities.

Instead:
1. Open a **Private Security Advisory** via GitHub:
   [Report a vulnerability](https://github.com/Morendais/mcp-audit/security/advisories/new)
2. Or contact the maintainer privately.

### What to Include
- Detailed description of the vulnerability and its attack vector.
- Minimal, non-destructive reproduction steps or PoC.
- Affected components (CLI, fuzzer, SARIF generator, or protocol parser).

### Response Timeline
- **Initial Response:** Within 48 hours.
- **Triage & Status Update:** Within 5 business days.
- **Fix & Public Advisory:** Coordinated with the reporter after testing.
